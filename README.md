# 🍔 Food Delivery App

Веб-приложение (или сервис) для удобного заказа и доставки еды. Позволяет пользователям выбирать заведения, формировать корзину и отслеживать статус своего заказа.

## ✨ Основной функционал
- **Каталог и меню:** удобный поиск блюд, фильтрация по категориям и ресторанам.
- **Корзина:** добавление/удаление позиций, изменение количества, автоматический расчет стоимости.
- **Оформление заказа:** выбор адреса доставки, времени и способа оплаты.
- **Отслеживание:** актуальные статусы заказа (принят, готовится, в пути, доставлен).
- **Личный кабинет:** история заказов и сохраненные адреса.
