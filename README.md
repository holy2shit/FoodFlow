# FoodFlow - Доставка еды

Сайт для заказа еды из ресторанов (Додо Пицца, Rostics, Супер Суши).

## Технологии:
- Python, Flask
- Microsoft Access (pyodbc)
- HTML, CSS, JavaScript

## Функционал:
- Каталог с фильтрами по магазинам и категориям
- Корзина (добавление, изменение количества, удаление)
- Оформление заказа с адресом
- Личный кабинет (история заказов, настройки профиля)
- Админ-панель (заказы, клиенты, отмена)

## Запуск:
1. `pip install flask pyodbc werkzeug`
2. `python app.py`
3. Открыть http://127.0.0.1:5000
